Game

LifeQuest

An interactive educational simulation built in Godot where players explore environments, interact with NPCs, and progress through scenario-based experiences.

Godot 4.6 GDScript 2D scenes NPC interactions Dialogue systems
Code

Problem

Civic and legal concepts can be difficult to understand through conventional educational material alone. LifeQuest explores a more interactive approach by putting the player into simulated situations.

Technology

Godot 4.6, GDScript, 2D scenes, character movement, collision detection, NPC interaction, dialogue systems, and scene transitions.

Result

Built a playable simulation MVP with explorable environments, player movement, NPC interactions, dialogue/text systems, and transitions between scenes. The project also secured 7th position in a college hackathon.

Learning

Learned how to structure a project using Godot's scene-based architecture and gained hands-on experience with GDScript, gameplay state flow, collisions, NPC interaction, dialogue, and scene management.

Grocery Inventory Management System

A full-stack inventory management system for grocery operations, covering product management, suppliers, purchases, sales, stock tracking, alerts, and reporting.

PostgreSQL HTML CSS JavaScript
Code

Problem

Managing grocery inventory requires keeping products, suppliers, purchases, sales, and stock levels consistent. This project was built to model those real-world workflows through a structured database-backed system.

Technology

PostgreSQL, HTML, CSS, JavaScript.

Result

Built an interactive inventory dashboard with product and supplier management, purchase and sales workflows, stock tracking, low-stock alerts, expiry tracking, sales analytics, and reporting. PostgreSQL functions, triggers, constraints, and views were used for validation, transaction processing, and reporting.

Learning

Gained practical experience designing relational database workflows and using PostgreSQL functions, triggers, constraints, and views to enforce business logic and maintain data consistency.

Discord Self-Bot

A Python-based Discord automation project that monitors selected channels, filters incoming messages, logs relevant activity, and can automatically send direct messages with configurable cooldowns and delays.

Python discord.py-self python-dotenv asyncio
Code

Problem

Managing and responding to relevant messages across Discord channels manually can be repetitive. This project explores automating message monitoring and responses through configurable filtering and event-driven processing.

Technology

Python, discord.py-self, python-dotenv, and asyncio.

Result

Built a modular Discord automation tool with channel monitoring, message filtering, message and attachment logging, automatic DMs, per-user cooldowns, and configurable/randomized delays.

Learning

Learned how to build event-driven Discord automation, handle asynchronous workflows, structure a Python project into separate modules, manage environment-based configuration, and implement filtering, cooldown, and delayed-response logic.
